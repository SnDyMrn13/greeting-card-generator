#Make a Silly Card

You answer 5 questions and a silly worded card is produced.
There are 8 different possible closings for each card that are selected randomly.
If a visitor tries 5 times in a row, there is a secret message for them.

##How it's built

-an 'index.html' + 'card.js' + 'style.css' .
-There is also a scripts folder with:
	'tick.js' + 'pause.js' + 'madlibs.js' + 'madlibs-working.js'.
